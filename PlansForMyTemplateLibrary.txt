08. Thư viện Binary Tree (Cây nhị phân):

- Traversal:
+ Preorder = Node - Left - Right.
    . Dạng đệ quy.
    . Dạng vòng lặp (sử dụng stack).
+ Inorder = Left - Node - Right.
    . In theo thứ tự tăng dần.
    . Dạng đệ quy.
    . Dạng vòng lặp (sử dụng stack).
+ Reverse Inorder = Right - Node - Left.
    . In theo thứ tự giảm dần.
    . Dạng đệ quy.
    . Dạng vòng lặp (sử dụng stack).
+ Postorder = Left - Right - Node.
    . Dạng đệ quy.
    . Dạng vòng lặp (sử dụng stack).
+ Levelorder = Duyệt theo từng tầng của cây.
    . Sử dụng Queue.

- isCompleteTree (Kiểm tra xem Binary Tree có phải là Complete Tree hay không ?):
+ Complete Tree (Cây hoàn chỉnh) là cây mà ở tẩng cuối cùng được làm đầy từ trái sang phải.

- isPerfectTree (Kiểm tra xem Binary Tree có phải là Perfect Tree hay không ?):
+ Perfect Tree (Cây hoàn hảo) là cây mà ở tầng cuối cùng được làm đầy.

- isFullTree (Kiểm tra xem Binary Tree có phải là Full Tree hay không ?):
+ Full Tree (Cây đầy đủ) là cây mà mỗi node hoặc không có con, hoặc có đủ con.

- isBinarySearchTree (Kiểm tra xem Binary Tree có phải là Binary Search Tree hay không ?):
+ Binary Search Tree (Cây nhị phân tìm kiếm) là cây mà mỗi node đều lớn hơn cây con trái và nhỏ hơn cây con phải.

- isAVLTree (Kiểm tra xem Binary Tree có phải là AVL Tree hay không ?)
+ AVL Tree là Binary Search Tree mà mỗi node có chỉ số cân bằng (balance) là -1, 0, 1.
+ Chỉ số balance = Chiều cao cây con phải - Chiều cao cây con trái.

- isSymmetricTree (Kiểm tra xem Binary Tree có phải là Symmetric Tree hay không ?)
+ Symmetric Tree là cây đối xứng.
+ Dạng đệ quy.
+ Dạng vòng lặp (sử dụng queue).

- Search on Binary Search Tree.
+ Tìm kiếm nhị phân cơ bản.
+ Tìm phần tử lớn thứ k trong Binary Search Tree.
+ Tìm phần tử nhỏ thứ k trong Binary Search Tree.

- Tính chiều cao của cây.
+ Dạng đệ quy.
+ Dạng vòng lặp (sử dụng queue).

- Cập nhật chỉ số balance.

- Rotate (Xoay cây):
+ Lệch trái-trái: xoay phải một lần thì cây sẽ tự cân bằng.
+ Lệch phải-phải: xoay trái một lần thì cây sẽ tự cân bằng.
+ Lệch trái-phải: xoay trái rồi xoay phải thì cây sẽ tự cân bằng.
+ Lệch phải-trái: xoay phải rồi xoay trái thì cây sẽ tự cân bằng.

- Insert (Xây cây).

- Tìm node nhỏ nhất trong Binary Search Tree.

- Tìm node lớn nhất trong Binary Search Tree.

- Delete (Xóa cây):
+ Node bị xóa không có con: xóa node rồi trả về nullptr.
+ Node bị xóa có một con: xóa node rồi trả về con của nó.
+ Node bị xóa có hai con:
    . Tìm node lớn nhất bên cây con trái để thay thế node bị xóa.
    . Tìm node nhỏ nhất bên cây con phải để thay thể node bị xóa.
    . Lý do: hai node này sẽ có giá trị gần nhất với giá trị của node bị xóa.
    . Nhớ viết hàm deleteTree để xóa toàn bộ cây.

- Invert Binary Tree: lật ngược (mirror-flip) Binary Tree.

12. Thư viện Fenwick Tree = Binary Indexed Tree (Cây nhị phân được đánh chỉ số):

- Theory of Fenwick Tree:
+ Mặc dù Fenwick Tree là Binary Indexed Tree nhưng nó không phải là Binary Tree thực sự,
tức là nó không có struct Node hay nó không lưu left/right child. Fenwick Tree chỉ đơn thuần là một mảng.
+ Fenwick Tree is 1-based.
+ Lý do Fenwick Tree là 1-based:
    . Ta có: lowbit(idx) = idx & (-idx).
    . Nếu idx = 0 thì lowbit(idx) = lowbit(0) = 0 & 0 = 0.
    . Trong khi đó, ta cần idx += lowbit(idx) hoặc idx -= lowbit(idx) để di chuyển giữa các node,
    nếu idx = 0 thì lowbit(idx) = 0, dẫn đến idx += 0, ta không thể di chuyển giữa các node.
+ Fenwick Tree không lưu từng node giống Binary Tree thông thường, mà nó lưu bit[idx] lưu thông tin của một đoạn
kết thúc tại idx, độ dài đoạn là lowbit(idx).
+ Node parent của node idx là node thỏa mãn: parent = idx + lowbit(idx).
+ Ý nghĩa của node parent:
    . Node parent của node idx là node quản lý đoạn lớn hơn và chứa đoạn do node idx quản lý.
+ Thao tác update:
    . Công thức: idx += lowbit(idx) hay idx += idx & (-idx).
    . Mục đích: đi tới các node parent và cập nhật thông tin tại các node đó.
    . Nói cách khác, thao tác update cho node idx tức là ta sẽ cập nhật thông tin của các đoạn lớn hơn và chứa đoạn
    do node idx quản lý.
+ Thao tác query:
    . Công thức: idx -= lowbit(idx) hay idx -= idx & (-idx).
    . Mục đích: thay vì lấy thông tin của đoạn do node idx quản lý, ta chia đoạn đó thành các đoạn con không bị chồng lấn,
    rồi lấy thông tin trên từng đoạn con đó; sau đó, gộp các thông tin đó lại thành kết quả cuối cùng.

- Thao tác: update, query.

13. Thư viện Treap:

- Note:
+ Treap = Binary Search Tree + Heap.
+ Có hai loại: Explicit Treap và Implicit Treap.

- Thao tác: split, merge, insert, erase, query.
+ Node* merge(Node* a, Node* b): ghép mọi node trong a đứng trước b.

+ void split(Node* root, Node* &left, Node* &right, int k): tách thành
    . left = first k nodes.
    . right = remaining nodes.

+ insert:
    . split(root, A, B, pos).
    . root = merge(merge(A, newNode), B).

+ erase:
    . split(root, A, B, pos).
    . split(B, mid, C, 1).
    . delete mid.
    . root = merge(A, C).

+ query(left, right):
    . spilt(root, A, B, left).
    . split(B, mid, C, right - left + 1).
    . mid là đoạn cần query.
    . root = merge(...).
